Welcome to **Cineverse Hub**, a smart and modern movie and series recommender tailored for Indian and global cinema fans. Originally inspired as a clone, Cineverse Hub has evolved into a unique **OTT-style platform** designed to help you plan your 2025 watchlist with ease.


## ✨ Features

- 📅 **2025-Focused Content**: Discover only 2025 releases—no distractions.
- 🎞️ **Trailers & Teasers**: Watch high-quality trailers directly in the app.
- 🔍 **Effortless Search**: Instantly find titles by name or genre with optimized search.
- 📄 **Detailed Insights**: Access comprehensive overviews, genres, IMDb ratings, and release dates.
- 🖼️ **Mini-Thumbnail Previews**: Seamless visual scroll previews tailored for desktop users.
- 🔥 **Top 10 Trending**: Stay updated with the most popular and highly-rated titles.
- 🎥 **Sliding Cards**: Enjoy smooth, frictionless horizontal sliders for title browsing.
- ▶️ **Auto-Play on Hover**: Trailers automatically play after a 4-second hover on desktop banners.

## 🚀 Getting Started

Want to run Cineverse Hub locally? Follow these simple steps:

### Prerequisites
Make sure you have [Node.js](https://nodejs.org/) (v18 or higher) and `npm` installed.

### Installation

1. **Clone the repository**
   ```bash
   git clone https://github.com/Patel-Priyank-1602/movieweb-blog.git
   cd movieweb-blog
   ```

2. **Install dependencies**
   ```bash
   npm install
   ```

3. **Run the development server**
   ```bash
   npm run dev
   ```

4. **Open the app**
   Navigate to [http://localhost:3000](http://localhost:3000) in your browser to see the result.
